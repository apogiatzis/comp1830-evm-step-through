About this tool

The default program is the exact bytecode from the lab sheet: the Solidity compiler’s output for contract MyContract { uint i = 10 + 2 * 2; }. Running it is what happens when the contract is deployed: the constructor code runs once and returns the runtime code that is stored in the new contract account.

  • Stack: up to 1024 items of 32 bytes; most instructions take their inputs from the top of the stack and push their result back.
  • Memory: a temporary byte array, empty at the start of each call and expanded (for a gas fee) as it is used.
  • Storage: the contract’s permanent key → value store. Writing a new value costs far more gas than anything else, because every node must keep it forever.
  • REVERT and running out of gas undo every storage change; running out of gas also uses up all the gas provided.

This is a small teaching interpreter that implements only the instructions these programs use, with current (post-Berlin) gas costs. The transaction-cost breakdown also includes the fixed costs that every contract-creation transaction pays.
